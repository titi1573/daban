# 打板交易闭环(选股 → 打板买入 → 次日卖出 → 台账)

独立项目,与 `stock-review`(价值/动量选股)完全分离,两套体系互不混用。

## 一句话说明

从当日涨停池里,按"封板质量 + 连板高度 + 主线板块 + 情绪周期"筛选出**最可能次日继续涨停或高溢价**的票,挂涨停价买入(打板),次日按纪律卖出,并在台账里记录每笔实际盈亏。

## 闭环流程

```
① daban.py          选股: 当日涨停池 → 打板候选 → data/latest/daban.json
② ledger.py --buy   建仓: 读候选, 挂涨停价买入(整手/单票20%/最多5只/情绪差不打)
③ sell_sim.py       卖出: 次日拉K线, 按三规则卖出或持有, 记实际盈亏
④ ledger.py         台账: 查看账户(现金/持仓/已平仓/总资产/胜率) + 生成 data/LEDGER.md
```

## 用法

```bash
python daban.py            # ① 选股 (每日盘后)
python ledger.py --buy     # ② 建仓 (读 daban.json, 情绪差自动空仓)
python sell_sim.py         # ③ 次日卖出模拟 (每个交易日盘后跑)
python ledger.py           # ④ 查看台账
python ledger.py --reset   # 重置账户
```

依赖:`akshare`(东财涨停池 + 不复权日K线)。

A/B 开关:`python daban.py --no-yiziban` / `--no-20pct` / `--no-mainline` 可临时关闭对应过滤做对比。

## 选股规则(打什么板)

| 条件 | 阈值 | 说明 |
|---|---|---|
| 连板数 | ≤3 | 回测:连板越高平均收益越高,连板2+加分 |
| 炸板次数 | ≤1 | 最好一次封死 |
| 首次封板时间 | ≤10:30 | 早盘封板=强,尾盘板不碰 |
| 换手率 | 5~25% | 过低买不进/一字板,过高分歧大 |
| 流通市值 | ≤100亿 | 中小盘弹性大 |
| 封板资金 | ≥5000万 | 封单够厚 |
| 板块 | 主线 | 优选当日涨停家数最多的行业 |
| 一字板 | 排除 | 首封≤09:26(集合竞价封板)买不进 |
| 秒板 | 标记扣分 | 首封≤09:31(开盘秒封)可能买不进 |
| 20%板(创业/科创) | 只打首板 | 连板2+断板代价大,排除 |
| 连板2+ | 须主线 | 所属行业涨停家数≥3,否则排除 |
| ST | 排除 | 涨幅 5%、风险高 |

## 卖出规则(次日,已由 sell_sim.py 实现)

1. **不涨停 → 卖**(不板就走,收盘价成交,截断亏损)
2. **继续涨停 → 持有**(吃连板溢价,最多连续持有 5 日)
3. **低开 >3% → 无条件止损**(开盘价卖,复盘后从 5% 收紧)

仓位:单票 20%,分散 3~5 只,只买评分≥0 的票(起始资金 ¥1 万,可在 `ledger.py` 改 `CAPITAL`);情绪差(涨停<30 家或炸板率高)时少打/不打。

## 台账

`ledger.py` 维护 `data/ledger.json`(结构化状态)+ `data/LEDGER.md`(人类可读),记录每笔打板的买入日/买入价/卖出日/卖出价/股数/净盈亏/收益率/卖出原因,以及账户现金、市值、总资产、胜率。

费用模型:A股佣金万 2.5(最低 ¥5)、卖出印花税 0.05%。

## ⚠️ 风险警告

- **打板 = 追涨停**,是"低胜率、高赔率"的高风险游戏,首板晋级率通常仅 30~40%,大多数打板者亏损。
- **无法回测**:历史涨停池免费接口拿不到,本策略只做当日选股 + 次日模拟,**有效性未经验证**。
- 卖出模拟的局限:**"不板就走"用收盘价成交近似**(无分钟数据,无法模拟盘中破板);打板买入价用涨停价近似(假设封板成交)。
- 所谓"利润最大化",真相是**靠连板股的大溢价覆盖断板股的小亏损**,靠的是"不板就走"的铁律 + 仓位控制,不是每笔都赚。
- 本项目为**选股 + 模拟台账**,不含自动交易、不含资金管理,仅供参考学习,不构成投资建议。
