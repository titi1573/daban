# 打板选股器(追涨停)

独立项目,与 `stock-review`(价值/动量选股)完全分离,两套体系互不混用。

## 一句话说明

从当日涨停池里,按"封板质量 + 连板高度 + 主线板块 + 情绪周期"筛选出**最可能次日继续涨停或高溢价**的票,挂涨停价买入(打板),次日按纪律卖出。

## 用法

```bash
python daban.py
```

输出:`data/latest/daban.json` + 控制台候选列表。

依赖:`akshare`(东财涨停池,仅当日数据)。

## 选股规则(打什么板)

| 条件 | 阈值 | 说明 |
|---|---|---|
| 连板数 | ≤3 | 打首/二/三板,不追 4 板以上高标 |
| 炸板次数 | ≤1 | 最好一次封死 |
| 首次封板时间 | ≤10:30 | 早盘封板=强,尾盘板不碰 |
| 换手率 | 5~25% | 过低买不进/一字板,过高分歧大 |
| 流通市值 | ≤100亿 | 中小盘弹性大 |
| 封板资金 | ≥5000万 | 封单够厚 |
| 板块 | 主线 | 优选当日涨停家数最多的行业 |
| ST | 排除 | 涨幅 5%、风险高 |

## 卖出规则(次日,利润最大化的关键)

1. **不涨停 → 卖**(不板就走,截断亏损)
2. **继续涨停 → 持有**(吃连板溢价)
3. **低开 >5% → 无条件止损**

仓位:单票 10~20%,分散 3~5 只;情绪差(涨停<30 家或炸板率高)时少打/不打。

## ⚠️ 风险警告

- **打板 = 追涨停**,是"低胜率、高赔率"的高风险游戏,首板晋级率通常仅 30~40%,大多数打板者亏损。
- **无法回测**:历史涨停池免费接口拿不到,本策略只做当日选股,**有效性未经验证**。
- 所谓"利润最大化",真相是**靠连板股的大溢价覆盖断板股的小亏损**,靠的是"不板就走"的铁律 + 仓位控制,不是每笔都赚。
- 本项目为**选股器**,不含自动交易、不含资金管理,仅供参考学习,不构成投资建议。
